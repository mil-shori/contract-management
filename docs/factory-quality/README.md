# 食品工場 品質担保システム — 設計ドキュメント

工場拡大に伴う品質担保の課題に対して、
**「録って話す」を共通部品として、経営者の暗黙知のナレッジ化・iPadボット・作業者の遵守確認**
を一体で設計したもの。

**実装は別リポジトリで行う。** ここにあるのは要件定義と設計であり、コードは含まない。

## 特に重要な3点

1. **[#09] 週1〜3の収録PoCを飛ばさない。** コードを書く前に10本録って、
   工場騒音下の文字起こし精度とカードの質を実測する。ここが最大の技術リスク。
2. **[#05] 承認を自動化しない。** AIが起案した誤ったマニュアルが現場に出るのは、
   マニュアルが無いより悪い。
3. **[#01] 手順書の欠陥を人の問題にしない。** 「守らない人がいる」の多くは、
   手順が現場と合っていないか、なぜが説明されていないことに起因する。
