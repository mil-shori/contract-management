# 付録C: 巡回・点検テンプレート

**自由に喋ると必ず抜ける。ルートと質問を固定して、それに沿って録る。**

---

## C-1. 巡回ルート（固定）

```
受入 → 前処理 → 加熱 → 冷却 → 充填 → 包装 → 出荷
                              ↓
                    洗浄 → 更衣室 → ゴミ・排水
```

- 順番を変えない。同じ順で録ると、後から比較できる
- 1ポイント1本（1〜3分）。全部を1本にしない
- 全ポイントを毎回回らなくてよい。**週で一巡すればよい**

---

## C-2. 各ポイントで自分に向ける4つの質問

録画を始めたら、この順で声に出す。**この4つが暗黙知を引き出す装置。**

1. **今日ここで一番危ないのは何か**
2. **昨日と違うところはどこか**
3. **基準は何で、いま実際どうなっているか**
4. **これが崩れると、最終的に何が起きるか**

4番目が `why` になる。**ここを飛ばすと、守られないマニュアルができる。**

### 言い方の例

> 「充填機の前です。今日ここで一番危ないのは、充填量のばらつき。
> 昨日と違うのは、朝から気温が高いこと。原料の粘度が変わる。
> 基準は規定±2gで、3個連続で見る。1個だとたまたま入っただけかもしれないから。
> これが崩れると、内容量不足でロット丸ごと回収になる。去年それをやった。」

短いが、この中に `observe` `criteria` `why` `onNg` が全部入っている。

## C-3. 五感チェック

| 感覚 | 見るもの |
|---|---|
| **見る** | 色・つや・水濡れ・整列・掲示物の更新日・シールの浮き・床の汚れの位置 |
| **聞く** | 異音・回転音の変化・エア漏れ・ベルトの擦れ |
| **触る** | 振動・熱・べたつき・ボルトの緩み |
| **嗅ぐ** | 異臭・洗剤の残り香・焦げ |
| **測る** | 温度・時間・重量・pH・濃度・圧力 |

**「聞く」「嗅ぐ」は記録に残りにくいので、意識して口に出す。**
異音は必ず**音声で録る**（C-5）。

---

## C-4. 人の観点

- 手洗い・手袋交換の**タイミング**（回数ではなく、いつ替えたか）
- 汚染区／清浄区の**動線の交差**
- 応援者・新人の入り方（誰がどこに立っているか）
- 私語・スマホ・疲労の様子
- **誰が誰に何を教えているか**（間違った教え方が伝播していないか）

---

## C-5. 記録類の観点

- 温度記録の**空欄**
- **後埋めの痕跡**（同じ筆圧・同じインク・時刻が不自然に揃っている）
- 掲示物の**版が古い**（更新日を見る）
- 期限切れのラベル・使いかけの原料の表示

**記録の逸脱は、実作業の逸脱より先に見つかる。** 記録が雑になり始めたら、
その工程で何かが起きている。

---

## C-6. 設備メンテナンス点検カード（設備ごとに1枚作る）

```
設備名:                          設備ID:
─────────────────────────────────────
部位 | 見る観点 | 基準 | 劣化の初期兆候 | 交換周期 | 前回交換日
─────────────────────────────────────
     |         |     |               |         |
```

### 記入時の要点

- **「劣化の初期兆候」が最も価値が高い。** 壊れてからでは遅い。
  「音が半音高くなる」「触ると前より温い」など、本人にしか書けないことを書く
- **過去の故障とその前兆**を必ず1行残す。「あのとき何が起きていたか」がナレッジになる
- 消耗品の在庫と交換履歴を紐付ける（次の交換時期が予測できる）

### 巡回時のやり方

1. **前回の記録を画面に出す**
2. 「前回はこう書いた。今日はどうか」を口に出す
3. **差分だけ話す。** 変化がなければ「前回と同じ」でよい

### 異音は必ず録る

- 「カラカラ言ってた」という記憶は比較できない。**音は比較できる**
- 10〜20秒の音声を、設備IDと日付で残す
- 同じ設備の音を時系列で並べられるようにしておく
- 3ヶ月前の音と今日の音を並べて聞くと、劣化が分かる

---

## C-7. 収録のコツ

| コツ | 理由 |
|---|---|
| **話しながら撮る** | 後から思い出して書くと、観点が抜け落ちる |
| **カメラを対象に向けてから話す** | 何の話をしているか、映像で特定できる |
| **数値を口に出す** | 「規定±2g」と言えば、文字起こしに残る |
| **固有名詞で言う** | 「あれ」「例のやつ」は用語辞書でも拾いきれない |
| **失敗談を入れる** | 「去年これで廃棄した」が最強の `why` になる |
| **1本1〜3分で切る** | 長いと上がらない・見返せない・切り出せない |
| **騒音源から離れる** | 話す間だけ1歩下がる。それだけで認識精度が変わる |

## C-8. 初回に録るべき10本（Phase 0 用）

PoC の10本は、次の配分で録る。

| # | 内容 | 目的 |
|---|---|---|
| 1〜3 | #01 §1 で診断した**守られていない工程3つ** | 一番効くところから |
| 4〜5 | **騒音の大きい工程** | STT 精度の判定（技術リスクの本命） |
| 6 | 設備メンテの観点（C-6） | 別の型が通るか |
| 7 | 異音の録音（音声のみ） | 音声だけの経路の確認 |
| 8 | 記録類の観点（C-5） | 「物」ではないものが構造化できるか |
| 9 | 判断の原則（`judgment_rule`）を1つ | 抽象的な内容が扱えるか |
| 10 | 予備・撮り直し | — |
